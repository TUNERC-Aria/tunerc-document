# OSD Module Document

## Specification
Input voltage: 3.6-6.5V  
Connector: 6-pin SUR 0.8mm (SPI protocol)  
OSD IC: AT7456ELAH  

## Wiring diagram when used with EZ3
This module includes a cable with identical connectors on both ends. When connecting to an EZ3 , simply cut off either end of the connector and solder the wires directly to the AIO.
